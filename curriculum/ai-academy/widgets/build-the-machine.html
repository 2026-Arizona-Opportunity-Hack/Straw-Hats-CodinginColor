Build the Machine

Trace one action: you type your name and save it. For each step, pick the part of the computer that does the job. You get feedback right away, so it is fine to guess and try again.

1Input: you press keys to type your name.

Correct! The keyboard is an input device. It brings your key presses into the computer.

Not quite. Input means bringing information in. Which part do your fingers touch?

2Processing: a program's instructions turn each key press into a letter.

Correct! The CPU follows the program's instructions. It does the processing.

Not quite. Processing means following instructions. Which part is often called the "brain"?

3Memory: while you type, your name is held in fast, temporary working space.

Correct! RAM holds the data the CPU is using right now. It is cleared when the power goes off.

Not quite. Look for the fast, short-term memory that forgets everything when the power goes off.

4Output: the letters of your name appear so you can see them.

Correct! The screen is an output device. It shows you the result.

Not quite. Output means showing or playing the result. Where do you see your letters?

5Storage: you click Save, so your name is still there after the computer turns off.

Correct! The SSD (or hard drive) keeps files even when the power is off.

Not quite. RAM forgets when the power goes off. Which part keeps files for next time?
